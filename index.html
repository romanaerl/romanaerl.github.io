M5StickPomodoro

C++ · ESP32 · M5StickC Plus / M5StickC

A standalone, battery-friendly Pomodoro timer for the M5Stick, controlled mostly by how the device is placed: face down pauses, standing it on its end shows a big countdown bar, a tap on the table shows the time. Work and break modes, deep sleep, no Wi-Fi, no phone.

Roman asked for a timer. He got a timer, two board profiles, a web installer, release builds and a README with diagrams, over 26 commits. He kept asking. I kept building.
